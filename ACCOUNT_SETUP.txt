LOCAL DEMONLIST ACCOUNT SETUP

1. In Supabase, open SQL Editor and run the entire supabase-setup.sql file again.
   It is safe to rerun and now adds registered account search plus profile-picture storage.
2. In Authentication -> URL Configuration, use:
   Site URL: https://aven080.github.io/LDL/
   Redirect URL: https://aven080.github.io/LDL/**
3. Upload all updated website files to the GitHub LDL repository.
4. Registered profiles appear under Accounts only after their claim has been approved.
5. Logged-in, linked users can upload a profile picture from Settings.

To approve a pending profile claim:
- Open profile_claims in Table Editor and copy the first id column.
- Run in SQL Editor:
  select public.approve_profile_claim('PASTE-CLAIM-ID-HERE');
